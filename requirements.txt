# ---------------------------------------------------------------------------
# Engine dependencies. Install in stages rather than all at once -- each pulls
# models on first use, and a failure is easier to attribute when it is isolated.
# All weights download automatically; nothing needs fetching by hand.
#
#   1. OCR (read + medicine modes)   ~100 MB of models, cheapest and proven
#      pip install paddlepaddle paddleocr
#
#   2. Speech (--lang mr --speak)    ~950 MB (IndicTrans2 200M + MMS-TTS voices)
#      pip install IndicTransToolkit
#
#   3. VLM (scene + ask modes)       ~4.5 GB (SmolVLM-Instruct)
#      already covered by transformers above
#
# Budget roughly 6 GB of disk. Measured on a CPU-only runtime 2026-08-10: SmolVLM
# takes 481s for a scene description and 315s for a question, against 1.2s on a
# Colab T4. Minutes, not "tens of seconds" -- see RISK-1 and DEC-038. OCR is 56s
# per photo; currency and the parsers are fast.
# ---------------------------------------------------------------------------
